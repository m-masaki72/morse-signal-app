モールス信号変換アプリについて

和文・欧文モールス信号の学習・練習を目的に作ったWebアプリです。入力した文字をモールス符号に変換し、音と光で再生します。

放射状のサンバースト樹形図でモールス符号の二分木構造をそのまま表現しており、再生中はパスがアニメーションでハイライトされます。「なぜこの符号なのか」が構造として見えるのが特徴です。

使い方

  1. 変換したい文字（ひらがな・カタカナ・英字）を入力します。
  2. モールス符号に変換され、ビープ音で再生できます。
  3. 樹形図のハイライトを見ながら、符号の成り立ちを確認しましょう。

主な機能・特徴

  • ひらがな入力を自動でカタカナに変換
  • 濁音（ガ→カ＋゛）も正しく分解して符号化
  • Web Audio API によるビープ音再生
  • 短点（青）・長点（オレンジ）で光の色が変わる視覚演出
  • 放射状サンバースト樹形図で符号の構造を可視化

よくある質問

無料で使えますか？
はい。無料で、会員登録やアプリのインストールも不要です。ブラウザでこのページを開くだけで使えます。
和文モールスにも対応していますか？
はい。和文（カナ）と欧文（アルファベット）の両方に対応しています。
